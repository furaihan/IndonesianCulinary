# Indonesian Culinary Mod

Selamat datang di Indonesian Culinary Mod untuk 7 Days to Die! 🍜

## Deskripsi

Indonesian Culinary membawa cita rasa kaya Indonesia ke pengalaman 7 Days to Die Anda. Temukan dan buat hidangan tradisional seperti Nasi Goreng, Sate Jamur, dan Rendang, masing-masing menawarkan buff unik dan nutrisi. Jelajahi warisan kuliner yang vibrant sambil bertahan di apocalypse.

## Fitur Utama

- **Sate Perpaduan**: Sate Jamur dan Sate Ayam dengan rasa autentik
- **Makanan Berkuah**: Kolak (obat diare), Tinutuan (kemungkinan bonus panen), Bakwan Jagung
- **Makanan Ringan**: Perkedel
- **Minuman Tradisional**: Wedang Uwuh (tahan terhadap kerusakan) dan Kopi Joss
- **Buff Unik**: Setiap hidangan memberikan buff khusus dan sustenance yang berbeda
- **Resep Crafting**: Gunakan bahan-bahan dan peralatan memasak untuk membuat hidangan
- **Item Icon Custom**: Atlas icon yang dirancang khusus untuk setiap item

## Instalasi

1. Download file mod terbaru dari repository ini
2. Extract folder `IndonesianCulinary` ke direktori `Mods` di folder instalasi 7 Days to Die
3. Struktur yang benar: `7DaysToDie/Mods/IndonesianCulinary/`
4. Jalankan game dan mod akan otomatis diload

## Struktur Proyek

```
IndonesianCulinary/
├── Config/                    # File konfigurasi mod
│   ├── buffs.xml             # Definisi buff untuk setiap hidangan
│   ├── items.xml             # Definisi item makanan
│   ├── loot.xml              # Konfigurasi loot dari zombie/treasure
│   ├── progression.xml        # Skill dan unlock progression
│   ├── recipes.xml           # Resep crafting untuk hidangan
│   ├── traders.xml           # NPC trader dan inventory mereka
│   ├── ui_display.xml        # Konfigurasi tampilan UI
│   └── Localization.txt      # File lokalisasi
├── UIAtlases/
│   └── ItemIconAtlas/        # Icon atlas untuk item
├── ModInfo.xml               # Informasi metadata mod
└── README.md                 # File dokumentasi ini
```
